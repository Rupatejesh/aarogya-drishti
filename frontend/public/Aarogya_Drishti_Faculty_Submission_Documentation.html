Autonomous AI Early Oral Cancer Detection, Tele-Consultation & Care Coordination System

Executive Summary: AAROGYA DRISHTI (ఆరోగ్య దృష్టి / आरोग्य दृष्टि) is an integrated, production-grade MERN-stack tele-oncology healthcare platform engineered specifically for the 11 tribal agency mandals of Alluri Sitharama Raju (ASR) District, Andhra Pradesh. The application bridges the rural healthcare divide for high-risk oral precancerous conditions (Leukoplakia, Erythroplakia, OSMF) driven by regional habits like "Adda Poga" (reverse smoking of cigars) through multimodal Gemini AI triage, encrypted peer-to-peer WebRTC video telemedicine, and 11 mandals administrative resource allocation.

SECTION 1: TECHNOLOGIES, TOOLS & MODELS USED

1.1 Front-End Architecture

  • Core Framework: React 18.3.1 with strict TypeScript 5.7.3 for type safety and zero runtime exceptions.
  • Build Tooling: Vite 5.4.14 with optimized rollup code splitting and instant Hot Module Replacement (HMR).
  • Design System & Color Palette: Tailwind CSS 3.4.17 strictly adhering to clinical color hierarchy:
    • Crisp Medical White (#FFFFFF / #F8FAFC) — Background shells, sterile clinical cards.
    • Royal Onco-Blue (#0A4D68 / #0284C7 / #1E3A8A) — Navigation, primary call-to-actions, trust anchors.
    • Teal / Cyan Accent (#088395 / #67E8F9) — Camera reticle guides and AI visual focus indicators.
    • Soft Clinical Amber (#D97706 / #FEF08A) — Triage warnings, Adda Poga risk tags, pending appointment cards.
    • Deep Crimson Red (#991B1B / #EF4444) — Biopsy mandate alerts, high-risk triage, and emergency 108 SOS.
  • Vector Icons: Lucide React 0.475.0 (tree-shakeable SVG clinical icons).
  • 3D Molecular Biomarker Model: Three.js 0.173.0 rendering an interactive 3D double helix visualizing p53 tumor suppressor and Ki-67 proliferative index with 360° mouse drag interaction.

1.2 Back-End Architecture

  • Runtime & Server: Node.js v24.21.0 executing Express.js 4.21.2 under modular REST routing (/api/v1/...).
  • Authentication & Security: jsonwebtoken 9.0.2 (stateless role-based JWT issuance), bcryptjs 3.0.3 (salted credential hashing), cors 2.8.5, and morgan 1.10.0 logging.
  • Image Storage & CDN: multer 1.4.5-lts.1 memory buffer paired with Cloudinary CDN and offline disk buffer fallback.

1.3 Database Architecture

  • Database Engine: MongoDB Community Edition & MongoDB Atlas Cloud Cluster (v8.0+).
  • Object Data Modeling (ODM): Mongoose 8.9.5 defining 8 isolated schemas: users, patients, doctors, hospitals, screenings, appointments, prescriptions, and auditlogs.
  • Resilient Dual-Mode Persistence Store: Disk-persisted in-memory database (backend/src/data/resilient_store.json) automatically synchronizing in real time with MongoDB. If MongoDB encounters a disruption, the application seamlessly continues with 0% downtime and 100% data preservation.

1.4 Real-Time Telemedicine & AI Infrastructure

  • Peer-to-Peer Protocol: WebRTC (RTCPeerConnection + getUserMedia) for encrypted, low-latency audio/video.
  • Signaling Server: Socket.io 4.8.1 on port 5000 with public Google STUN server (stun:stun.l.google.com:19302).
  • Multimodal Vision AI: Google Gemini Vision API (gemini-3.1-flash-lite) via @google/genai SDK for oral photo triage (>92% demonstration accuracy). Explicitly stamped: Advisory Screening — Not for Clinical Diagnosis.
  • Trilingual Voice Engine: Government of India Bhashini Neural Indian TTS paired with Web Speech API (te-IN, en-IN, hi-IN) and a persistent red Stop Voice (⏹️) control.

3.3 Security & Data Isolation Protocols

  • Strict Patient Boundary: Patients can query exclusively records matching their assigned UIDN. Cross-patient lookups are rejected at the controller level with 403 Forbidden.
  • Doctor Clinical Scope: Doctors possess clinical write access solely for patients under their active consultation queue.
  • Zero Media Recording: WebRTC video and audio streams flow strictly peer-to-peer. No patient video feeds or voice calls are ever stored or recorded on servers.
  • Input Sanitization: 12-digit Aadhaar regex, 10-digit mobile validation, and string trimming guard against injection vulnerabilities.

5.3 Honest Hackathon Limitations & Clinical Boundaries

1. Advisory Screening vs. Definitive Diagnosis: The multimodal AI model serves strictly as an early triage and advisory screening filter for health workers in rural agency areas. It is not a certified Software as a Medical Device (SaMD) and cannot replace microscopic tissue examination by a certified pathologist.

2. Synthetic Demonstration Registry: Citizen Aadhaar numbers and mobile OTPs are validated locally against official schema standards rather than live UIDAI / DigiLocker production gateways which require restricted institutional licenses.

3. WebRTC Enterprise Relays: The WebRTC implementation connects reliably across local networks, Wi-Fi, and public STUN servers (stun:stun.l.google.com:19302). In strict enterprise hospital networks behind symmetric firewalls, a dedicated TURN relay server (Coturn) would be provisioned.
